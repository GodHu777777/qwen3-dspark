# 既有 quality32 首位接受概率重析

三次采集共8,158个round，首位selected p0/q0均有效，无缺失或零round prompt。每个checkpoint保留原32个ordinal。这里只分析已完成的development轨迹，没有重新生成、训练或运行GPU。

alpha=min(1,p0/q0)是被抽中首位token的接受概率；拒绝风险是1-alpha。二元首prefix事件来自accepted≥1，已逐round与原prefix标签对照。

Pooled按round加权；equal-prompt先求每个prompt的均值，再对有有效分母的prompt等权。p/q未截断均值与alpha不同；少数大比值会影响前者，不能用其代替接受概率。三次输出总长度分别为3,874、3,941、3,856；EOS和达预算在定义上可同时发生，本次计数恰好分别覆盖32个prompt。

## 证据与边界

分析逐prompt核对完整outputs、round/block顺序、cache与commit、原始首prefix标签、所有位置计数及原run/aggregate。绑定与panel digest、原30模块collector源码、worker退出码均通过；root另核对published source identity/aggregate与controller/launcher退出证据。所有36个恢复输入在分析前后哈希一致。

当前恢复文件哈希证明恢复后字节身份，不是历史预先承诺的完整raw哈希。首位selected-token概率不是全词表逐状态overlap；round有关联，没有独立round置信区间。本结果不能直接归因于数据不匹配、曝光偏差或某个训练目标，也不授权继续训练、校准、策略搜索或速度推演。

完整公开安全的ordinal聚合见summary.json；逐round p/q、比值与alpha仅在private-round-risk.jsonl保留，不公开prompt ID、token内容或seed。
